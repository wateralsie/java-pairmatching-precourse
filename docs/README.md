# 미션 - 페어매칭관리 애플리케이션

## 구현 기능 목록
### 입출력
- [x] .md 파일에서 크루 이름 불러오기
- [x] 기능의 종류 출력
- [x] 단축키를 통한 기능 선택 (1, 2, 3, Q)
- [ ] 과정과 미션 출력
- [ ] 매칭하고자 하는 과정, 레벨, 미션 입력받기
- [ ] 기능 수행 종료 후 기능 선택 재유도
### 페어 매칭
- [ ] 페어 매칭
  - [ ] 크루 이름 목록 순서 랜덤화
  - [ ] 홀수인 경우 마지막 페어 세명으로 구성
  - [ ] 같은 레벨에서 같은 크루끼리 페어 매칭시 크루 이름 목록 재셔플
- [ ] 페어 재매칭
  - [ ] 안내 문구 출력 (다시 매칭하겠습니까?)
  - [ ] 아니오 선택 시, 코스, 레벨, 미션 다시 입력받기
- [ ] 페어 조회
  - [ ] 과정, 레벨, 미션 선택 시 해당 미션 페어 정보 출력
### 에러 처리
- [x] 크루 이름 불러올 수 없는 경우
- [ ] 페어 매칭에 실패한 경우 - 시도 3회 내로 매칭 실패
- [ ] 페어 조회 시 매칭 이력 없는 경우
